rcumsum

rcumsum(x, dim)[source]

Returns the reversely cumulative sum of elements of x in the dimension dim.

This is the reverse-direction counterpart of torch.cumsum(): the \(i\)-th output element is the sum of all elements at or after position \(i\) along the dimension. This is useful, for example, to compute the total of future values at each time step.

Parameters:

  • x (Tensor) – The input tensor.

  • dim (int) – The dimension along which to compute the reversely cumulative sum.

Returns:

A tensor of the same shape as the input, where each element is the sum of the input elements at or after its position along the dimension.

Return type:

Tensor

Example

>>> x = torch.tensor([1.0, 2.0, 3.0, 4.0])
>>> QF.rcumsum(x, dim=0)
tensor([10.,  9.,  7.,  4.])

Note

NaN values propagate in the direction of accumulation: because the accumulation runs from the end of the dimension, all positions at or before a NaN become NaN.

See also

  • rcummax(): Reversely cumulative maximum function.

  • nancumsum(): NaN-aware cumulative sum function.

  • torch.cumsum: Standard (forward) cumulative sum.
