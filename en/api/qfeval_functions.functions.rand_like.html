rand_like

rand_like(input, *, dtype=None, device=None)[source]

Returns a tensor with the same size as input that is filled with random numbers from a uniform distribution on the interval \([0, 1)\).

Unlike torch.rand_like(), if the seed is fixed with qfeval_functions.random.seed(), the result must be reproducible on any device. See rand() for details.

Parameters:

  • input (Tensor) – The input tensor whose shape, dtype, and device determine those of the output tensor.

  • dtype (torch.dtype, optional) – The desired data type of the returned tensor. Default is the dtype of input.

  • device (torch.device, optional) – The desired device of the returned tensor. Default is the device of input.

Returns:

A tensor with the same shape as input filled with uniform random numbers in \([0, 1)\).

Return type:

Tensor

Example

>>> import qfeval_functions
>>> with qfeval_functions.random.seed(1):
...     x = QF.rand_like(torch.zeros(2, 3, dtype=torch.float64))
>>> x
tensor([[0.2407, 0.7296, 0.5584],
        [0.5268, 0.1469, 0.9072]], dtype=torch.float64)

See also

  • rand(): Uniform random tensor with a specified shape.

  • randn_like(): Normal random tensor with the shape of another tensor.
