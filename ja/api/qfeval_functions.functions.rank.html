rank

rank(x, dim=-1, pct=True)[ソース]

指定された次元に沿って要素のクロスセクショナルな順位を計算します。

この関数は、指定された次元に沿って有効な（NaN でない）すべての要素を昇順に順位付けし、同順位は 1 始まりの順位の平均によって解決します。NaN 値は出力においてもその位置に NaN として保持され、順位付けとパーセンタイルの分母のいずれからも除外されます。結果は、同じ軸に沿って適用した pandas.DataFrame.rank(method="average", na_option="keep", pct=pct) と互換です。

有効な要素の順位は以下のように計算されます：

\[\text{RANK}[i] = \#\{j : x[j] < x[i]\} + \frac{\#\{j : x[j] = x[i]\} + 1}{2}\]

ここで、\(j\) は選択された次元に沿った有効な要素の範囲を動きます。pct が true の場合、順位はさらに有効な要素数 \(N_{\text{valid}}\) で除算されます。

パラメータ:

  • x (Tensor) -- 値を含む入力テンソル。浮動小数点テンソルである必要があります。無限大の値は有効な値であり、最小（\(-\infty\)）または最大（\(+\infty\)）の値として順位付けされます。

  • dim (int, optional) -- 要素を順位付けする次元。デフォルトは -1（最後の次元）です。

  • pct (bool, optional) -- True の場合、パーセンタイル順位、すなわち平均順位を有効な要素数で除算した値を返します。この値は \((0, 1]\) の範囲にあります。False の場合、1 始まりの平均順位を返します。この値は \([1, N_{\text{valid}}]\) の範囲にあります。デフォルトは True です。

戻り値:

順位の値を含む、入力と同じ形状のテンソル。入力で NaN であった位置は、出力でも NaN になります。

戻り値の型:

Tensor

例外:

TypeError -- x が浮動小数点テンソルでない場合。

サンプル

>>> # パーセンタイル順位（デフォルト）
>>> x = torch.tensor([3.0, 1.0, 2.0])
>>> QF.rank(x)
tensor([1.0000, 0.3333, 0.6667])

>>> # 1 始まりの平均順位
>>> QF.rank(x, pct=False)
tensor([3., 1., 2.])

>>> # 同順位は平均順位によって解決されます。
>>> QF.rank(torch.tensor([1.0, 1.0, 2.0]), pct=False)
tensor([1.5000, 1.5000, 3.0000])

>>> # NaN 値はその位置に保持され、パーセンタイルの分母には
>>> # 影響しません。
>>> QF.rank(torch.tensor([2.0, nan, 1.0]))
tensor([1.0000,    nan, 0.5000])

>>> # 無限大の値は最小/最大の値として順位付けされます。
>>> QF.rank(torch.tensor([1.0, inf, -inf, nan]), pct=False)
tensor([2., 3., 1., nan])

>>> # 各行に沿って順位を計算する 2 次元テンソル
>>> x = torch.tensor([[1.0, 3.0, 2.0],
...                   [3.0, 1.0, 2.0]])
>>> QF.rank(x, dim=1, pct=False)
tensor([[1., 3., 2.],
        [3., 1., 2.]])

注釈

次元に沿ったすべての要素が NaN の場合、結果はそのすべてで NaN になります。有効な要素が 1 つだけのスライスでは、順位は 1.0 になります（パーセンタイル順位としても 1.0 です）。

注釈

実装は入力をソートした後、各要素を二分探索によって特定するため、長さ \(N\) の各スライスに対して \(O(N \log N)\) の時間がかかります。

参考

  • mrank(): この関数の移動（スライディングウィンドウ）版。

  • zscore(): クロスセクショナルな標準化。次元に沿って値を正規化するもう 1 つの方法。

  • winsorize(): 極端な値のクロスセクショナルなクリッピング。
