pca

pca(x)[ソース]

与えられた入力 x に対して主成分分析（PCA）を計算します。

この関数は、セクション次元に沿って入力観測値の共分散行列を計算し、特異値分解によって主成分を抽出します。主成分は説明分散の降順で返されます。具体的には、components[*, i, :] は * で指定されたバッチの \((i+1)\) 番目に大きい主成分を表します。

qfeval では、次元とセクションはそれぞれ銘柄（シンボル）とタイムスタンプを表すことがよくあります。

パラメータ:

x (Tensor) -- 観測値を含む入力テンソル。

戻り値:

以下の要素を含むデータクラス:

  • components (Tensor): 形状 \((*, D, D)\) の主成分（共分散行列の固有ベクトル）。components[..., i, j] は第 \(i\) 成分の第 \(j\) 次元に対する重みを表します。

  • explained_variance (Tensor): 形状 \((*, D)\) の、各成分によって説明される分散（共分散行列の固有値）。降順に並びます。

戻り値の型:

PcaResult

形状:

  • x: \((*, S, D)\) ここで、* は任意の追加次元数を、S はセクション数を、D は次元数をそれぞれ表します。

サンプル

>>> x = torch.tensor([[2.0, 0.0],
...                   [0.0, 1.0],
...                   [-2.0, 0.0],
...                   [0.0, -1.0]])
>>> result = QF.pca(x)
>>> result.components
tensor([[1., 0.],
        [0., 1.]])
>>> result.explained_variance
tensor([2.6667, 0.6667])

注釈

各主成分の符号は任意です。主成分は符号を除いてのみ定義されるため、等価な入力に対して -1 倍された主成分が返されることがあります。

参考

  • pca_cov(): 実装に使用されている、計算済みの共分散行列に対する PCA。

  • nanpca(): NaN を考慮した主成分分析。

  • covar(): 実装に使用されている共分散関数。
