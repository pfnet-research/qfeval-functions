naninterp

naninterp(x, dim=-1)[ソース]

有効値の間にある NaN 値を線形補間します。

この関数は、指定された次元に沿って、2 つの有効値（NaN でない値）に厳密に挟まれた各 NaN 値を、その線形補間で置き換えます。位置 \(t\) にある NaN について、直前の有効な隣接値の位置を \(p\)、その値を \(v_p\)、直後の有効な隣接値の位置を \(n\)、その値を \(v_n\) とすると、結果は次のようになります:

\[y[t] = v_p + (v_n - v_p) \cdot \frac{t - p}{n - p}\]

片側に有効な隣接値を持たない先頭および末尾の NaN 値は、NaN のまま残ります。有効値は変更されずにそのまま返されます。これは pandas の Series.interpolate(method="linear", limit_area="inside") と一致し、末尾の NaN 値まで前方補完してしまう pandas のデフォルトの interpolate() とは異なります。

パラメータ:

  • x (Tensor) -- 補間する値を含む入力テンソル。浮動小数点テンソルである必要があります。

  • dim (int, optional) -- 補間を行う次元。デフォルトは -1 で、最後の次元を意味します。

戻り値:

入力と同じ形状のテンソルで、内側（有効値に挟まれた区間）の NaN 値は線形補間で置き換えられます。先頭および末尾の NaN 値は NaN のままです。

戻り値の型:

Tensor

例外:

TypeError -- x が浮動小数点テンソルでない場合。

サンプル

>>> QF.naninterp(torch.tensor([0.0, nan, nan, 3.0]))
tensor([0., 1., 2., 3.])

>>> # 先頭と末尾の NaN は NaN のままになります。
>>> QF.naninterp(torch.tensor([nan, 1.0, nan, 2.0, nan]))
tensor([   nan, 1.0000, 1.5000, 2.0000,    nan])

>>> # dim=1 を指定した 2 次元の例
>>> x = torch.tensor([[1.0, nan, 3.0],
...                   [10.0, nan, 20.0]])
>>> QF.naninterp(x, dim=1)
tensor([[ 1.,  2.,  3.],
        [10., 15., 20.]])

注釈

無限大の値は有効な値として扱われ、そのまま保持されます。±inf に隣接するギャップは IEEE 754 演算に従って埋められます。例えば、有限値と inf の間の補間は、方向に応じて inf または NaN になります。
