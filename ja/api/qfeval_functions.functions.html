関数 (qfeval_functions.functions)

apply_for_axis

指定された次元に沿ってテンソルに 2 次元入力を期待する関数を適用します。

bfill

指定された次元に沿って欠損値を後方補完します。

bincount

テンソル内の各値の出現回数をカウントします。

bollinger_band

テンソルのボリンジャーバンドを計算します。

correl

2 つのテンソル間のピアソン相関係数を計算します。

covar

指定された次元に沿って、2 つのテンソル間の共分散を計算します。

cumcount

指定した次元に沿って、各一意値の出現回数をカウントします。

eigh

対称行列（エルミート行列）の固有値と固有ベクトルを計算します。

einsum

アインシュタイン記法を用いて、指定されたインデックスにわたるテンソル要素の積を計算します。

ema

指定された次元に沿って指数移動平均を計算します。

ffill

指定された次元に沿って欠損値を前方の値で埋めます。

fillna

NaN および無限大の値を指定した数値に置換します。

gaussian_blur

指定された次元に沿ってテンソルにガウシアンぼかしを適用します。

group_shift

マスクされた位置をスキップしながら、指定された次元に沿ってテンソルの要素をシフトします。

groupby

指定された次元に沿ってテンソル要素をグループ識別子でグループ化します。

ma

テンソルの移動平均（スライディングウィンドウ平均）を計算します。

mmax

テンソルの移動最大値（スライディングウィンドウ最大値）を計算します。

mmin

テンソルの移動最小値（スライディングウィンドウ最小値）を計算します。

mstd

テンソルの移動標準偏差（スライディングウィンドウ標準偏差）を計算します。

msum

テンソルの移動和（スライディングウィンドウ和）を計算します。

mulmean

要素ごとの積の平均をメモリ効率の良い方法で計算します。

mulsum

要素ごとの積の和または平均をメモリ効率の良い方法で計算します。

mvar

テンソルの移動分散（スライディングウィンドウ分散）を計算します。

nanamax

NaN 値を無視して、指定された次元に沿ってテンソル要素の最大値を計算します。

nanamin

NaN 値を無視して、指定された次元に沿ってテンソル要素の最小値を計算します。

nancorrel

NaN 値を無視して、2 つのテンソル間のピアソン相関係数を計算します。

nancovar

NaN 値を無視して、2 つのテンソル間の共分散を計算します。

nancumprod

次元に沿って累積積を計算し、NaN を 1 として扱います。

nancumsum

次元に沿って累積和を計算し、NaN を 0 として扱います。

nankurtosis

NaN 値を無視して、指定された次元に沿って尖度を計算します。

nanmax

指定した次元に沿って最大値と対応するインデックスを返し、NaN 値は無視します。

nanmean

NaN 値を無視して、指定された次元に沿って算術平均を計算します。

nanmin

指定した次元に沿って最小値と対応するインデックスを返し、NaN 値は無視します。

nanmulmean

メモリ効率に優れた方法で、NaN 値を無視した要素ごとの積の平均値を計算します。

nanmulsum

メモリ効率に優れた方法で、NaN 値を無視した要素ごとの積の総和を効率的に計算します。

nanones

入力テンソルの NaN 位置を保持したまま、1 で埋められたテンソルを作成します。

nanpca

NaN 値を無視して、データに対して主成分分析（PCA）を計算します。

nanshift

NaN の位置を保持しながら、指定された次元に沿ってテンソルの要素をシフトします。

nanskew

NaN 値を無視して、指定された次元に沿って歪度を計算します。

nanslope

NaN 値を無視して、2 つのテンソル間の単回帰の傾きを計算します。

nansum

NaN 値を無視して、指定された次元に沿ってテンソル要素の和を計算します。

nanvar

NaN 値を無視してテンソルの分散を計算します。

orthogonalize

指定された次元に沿って、x を y に対して直交化します。

orthonormalize

与えられたベクトルを正規直交化し、対応する正規直交ベクトルを返します。

pca

与えられた入力 x に対して主成分分析（PCA）を計算します。

pca_cov

与えられた共分散行列 cov に対して主成分を計算します。

project

与えられたテンソル x を、指定された射影行列 a を用いて投影します。

rand

区間 \([0, 1)\) 上の一様分布に従う乱数で埋められたテンソルを返します。

rand_like

区間 \([0, 1)\) 上の一様分布に従う乱数で埋められた、input と同じサイズのテンソルを返します。

randint

low（含む）から high（含まない）の間で一様に生成されたランダムな整数で埋められたテンソルを返します。

randn

平均 0、分散 1 の正規分布に従う乱数で埋められたテンソルを返します（標準正規分布とも呼ばれます）。

randn_like

平均 0、分散 1 の正規分布に従う乱数で埋められた、input と同じサイズのテンソルを返します。

randperm

0 から n - 1 までの整数をランダムに並べ替えた配列を返します。

rci

指定された次元に沿って順位相関指数（RCI）を計算します。

rcummax

次元 dim における x の要素の逆方向累積最大値を返します。

rcumsum

次元 dim における x の要素の逆方向累積和を返します。

reduce_nan_patterns

グループシフト用のマスクを作成します。

rms

指定された次元 dim において、入力テンソルの各行の二乗平均平方根を返します。

rsi

指定された次元に沿って相対力指数（RSI）を計算します。

shift

指定された次元に沿って配列要素をシフトし、空いた位置を NaN で埋めます。

signif

指定された有効桁数にテンソルの数値を丸めます。

skipna

NaN 値を除去した後、与えられたデータを指定された関数に適用します。

slope

指定された次元 dim において、y を x に回帰させた単回帰の傾きを返します。

soft_topk

指定した次元に沿って微分可能な（ソフトな）top-k 選択を適用します。

soft_topk_bottomk

指定された次元に沿って、微分可能な（ソフトな）top-k/bottom-k 選択を適用します。

stable_sort

等価な要素の順序を保持しながら与えられたテンソルをソートします。
