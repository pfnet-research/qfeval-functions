mulmean

mulmean(x, y, dim=None, keepdim=False, *, _ddof=0)[ソース]

要素ごとの積の平均をメモリ効率の良い方法で計算します。

この関数は、中間的な積テンソルをメモリ上に作成することなく、2 つのテンソルの要素ごとの積 (x * y) の平均値 .mean(dim) を計算します。これは、メモリ効率が極めて重要な大規模テンソルを扱う場合や、テンソル間のブロードキャスト操作によって非常に大きな中間テンソルが生成される場合に特に有用です。

この関数は数学的には (x * y).mean(dim) と等価ですが、完全な積テンソルをメモリ上に展開しないよりメモリ効率の高い実装を採用しています。

パラメータ:

  • x (Tensor) -- 最初の入力テンソル。

  • y (Tensor) -- 第 2 の入力テンソル。x とブロードキャスト可能である必要があります。

  • dim (None, int, or tuple of ints, optional) -- 平均を計算する次元を指定します。None（デフォルト）の場合は、すべての次元にわたって平均が計算されます。

  • keepdim (bool, optional) -- 出力テンソルが dim を保持するかどうか。デフォルトは False。

  • _ddof (int, optional) -- 内部計算で使用する自由度のデルタ値。使用する除数は N - _ddof で、ここで N は要素数を表します。デフォルト値は 0 です。これは内部パラメータです。

戻り値:

要素ごとの積の平均値。形状は入力次元、dim パラメータ、および keepdim パラメータに依存します。

戻り値の型:

Tensor

サンプル

>>> # 単純な要素ごとの積の平均
>>> x = torch.tensor([1.0, 2.0, 3.0, 4.0])
>>> y = torch.tensor([2.0, 3.0, 4.0, 5.0])
>>> QF.mulmean(x, y)
tensor(10.)

>>> # (x * y).mean() と等価
>>> torch.allclose(QF.mulmean(x, y), (x * y).mean())
True

>>> # 次元を指定した 2 次元テンソル
>>> x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
>>> y = torch.tensor([[2.0, 1.0], [1.0, 2.0]])
>>> QF.mulmean(x, y, dim=1)
tensor([2.0000, 5.5000])

>>> # ブロードキャストの例
>>> x = torch.randn(1000, 1)
>>> y = torch.randn(1, 1000)
>>> # メモリ効率が良い: 1000x1000 の中間テンソルを作らない
>>> result = QF.mulmean(x, y)

>>> # keepdim を使用
>>> x = torch.tensor([[[1.0, 2.0]], [[3.0, 4.0]]])
>>> y = torch.tensor([[[2.0, 1.0]], [[1.0, 2.0]]])
>>> QF.mulmean(x, y, dim=(1, 2), keepdim=True)
tensor([[[2.0000]],

        [[5.5000]]])
