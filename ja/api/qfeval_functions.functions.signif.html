signif

signif(x, decimals=6)[ソース]

指定されたテンソルの数値を、指定された有効桁数に丸めます。

小数点以下の固定桁数に丸める torch.round() と異なり、この関数は指定された有効桁数を保つため、丸めの精度は各要素の大きさに応じて変化します（例: 有効数字 3 桁への丸めでは、12345 は 12300 に、0.012345 は 0.0123 になります）。これは R の signif 関数と同じ動作であり、デフォルトの桁数もそれに従います。ゼロおよび有限でない値（NaN と無限大）はそのまま返されます。

パラメータ:

  • x (Tensor) -- 入力テンソル。

  • decimals (int, optional) -- 保持する有効桁数。デフォルトは R の signif 関数と同じく 6 です。

戻り値:

各要素が指定された有効桁数に丸められた、入力と同じ形状のテンソル。

戻り値の型:

Tensor

サンプル

>>> x = torch.tensor([3.14159265, 2.71828183])
>>> QF.signif(x, 3)
tensor([3.1400, 2.7200])

>>> # ゼロはそのまま保持され、桁の大きさは要素ごとに適応します。
>>> x = torch.tensor([0.0, 100.0])
>>> QF.signif(x, 3)
tensor([  0., 100.])

参考

  • torch.round: 有効数字ではなく小数点以下の桁数で丸めます。
