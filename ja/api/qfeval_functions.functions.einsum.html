einsum

einsum(equation, *operands)[ソース]

アインシュタイン記法を用いて、指定されたインデックス範囲にわたるテンソル要素の積を合計します。

この関数は torch.einsum を型付けされたラッパーとして提供し、より優れた静的型解析を可能にします。アインシュタイン和記法を用いることで、行列積、バッチ行列積、点積、ブロードキャスト演算など、多くのテンソル演算を簡潔な記法で表現できます。

パラメータ:

  • equation (str) -- 和算の添字を記述する文字列です。文字列には、各演算子の添字ラベルがカンマ区切りで並び、その後に -> と出力の添字ラベルが続きます。

  • *operands (Tensor) -- 演算対象の入力テンソル。演算子の数は方程式中のカンマ区切りグループの数と一致している必要があります。

戻り値:

アインシュタイン和の計算結果。式中の出力添字ラベルによって形状が決定されます。

戻り値の型:

Tensor

サンプル

>>> # 行列積: "ij,jk->ik"
>>> A = torch.randn(3, 4)
>>> B = torch.randn(4, 5)
>>> C = QF.einsum("ij,jk->ik", A, B)
>>> C.shape
torch.Size([3, 5])

>>> # バッチ行列積: "bij,bjk->bik"
>>> A = torch.randn(10, 3, 4)
>>> B = torch.randn(10, 4, 5)
>>> C = QF.einsum("bij,bjk->bik", A, B)
>>> C.shape
torch.Size([10, 3, 5])

>>> # 行列のトレース: "ii->"
>>> A = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
>>> trace = QF.einsum("ii->", A)
>>> trace
tensor(5.)

>>> # 転置: "ij->ji"
>>> A = torch.randn(3, 4)
>>> A_T = QF.einsum("ij->ji", A)
>>> torch.allclose(A_T, A.T)
True
