stable_sort

stable_sort(x, dim=-1)[ソース]

与えられたテンソルを、等価な要素の順序を保持したままソートします。

この関数は、指定された次元に沿って要素を昇順にソートし、等しい値を持つ要素が元の相対順序を保つこと（すなわち安定ソート）を保証します。NaN 値は末尾に配置され、これらも元の相対順序を保ちます。デフォルトのアルゴリズムが安定性を保証しない torch.sort() と異なり、この関数は常に決定的なインデックスを返します。

パラメータ:

  • x (Tensor) -- 入力テンソル。

  • dim (int, optional) -- ソートを行う次元。デフォルトは -1（最後の次元）です。

戻り値:

(values, indices) の名前付きタプル:

  • values (Tensor): ソートされた値。入力と同じ形状です。

  • indices (Tensor): ソートされた値の元のテンソルにおけるインデックス。

戻り値の型:

StableSortResult

サンプル

>>> # 2 つの 1.0 は元の順序を保ちます（インデックス 1 が 3 より前）。
>>> x = torch.tensor([3.0, 1.0, 2.0, 1.0])
>>> result = QF.stable_sort(x)
>>> result.values
tensor([1., 1., 2., 3.])
>>> result.indices
tensor([1, 3, 2, 0])

>>> # NaN 値は末尾に配置されます。
>>> x = torch.tensor([2.0, nan, 1.0])
>>> result = QF.stable_sort(x)
>>> result.values
tensor([1., 2., nan])
>>> result.indices
tensor([2, 0, 1])
