atr

atr(high, low, close, span=14, use_sma=False, dim=-1)[ソース]

指定された次元に沿って ATR（Average True Range）を計算します。

ATR は、トゥルーレンジ（True Range）を平均するボラティリティ指標です。トゥルーレンジは、現在の足の高値から安値までの値幅と、直前の終値からの価格ギャップ（窓）の絶対値のうち、最大のものです:

\[\text{TR}[i] = \max\bigl(\text{high}[i] - \text{low}[i], \lvert\text{high}[i] - \text{close}[i-1]\rvert, \lvert\text{low}[i] - \text{close}[i-1]\rvert\bigr)\]

3 つの入力テンソルは相互にブロードキャストされ、トゥルーレンジはブロードキャスト後の形状に対して要素ごとに計算されます。

2 つの平均化手法がサポートされています:

  • use_sma=False（デフォルト）: ワイルダー平滑化（指数移動平均の一種）。NaN の扱いを除いて TA-Lib と互換性があります（下記の注記を参照）。次元に沿ったインデックス span の位置の出力は最初の span 個のトゥルーレンジの単純平均であり、それ以降の値は次の式に従います。

    \[\text{ATR}[i] = \frac{\text{ATR}[i-1] \times (\text{span} - 1) + \text{TR}[i]}{\text{span}}\]

    https://www.investopedia.com/terms/a/atr.asp を参照してください。

  • use_sma=True: 直近 span 個の要素にわたるトゥルーレンジの単純移動平均。日本のテクニカル分析の文献で一般的に用いられる方式です。

次元に沿った最初の要素には直前の終値が存在しないため、そのトゥルーレンジは未定義であり、出力の次元に沿った最初の span 個の要素は NaN になります。ATR 値を 1 つ計算するには span 個のトゥルーレンジ、すなわち span + 1 本の足が必要であるため、次元の要素数が span 以下の場合、出力形状はブロードキャスト後の入力形状と一致したまま、すべての出力値が NaN になります。

入力に含まれる NaN 値は、有効な ATR 値に変換されるのではなく、出力に伝播します:

  • use_sma=False（ワイルダー平滑化）: NaN のトゥルーレンジが初期平均または再帰的な平滑化に入った時点以降、すべての出力が NaN になります。

  • use_sma=True（単純移動平均）: NaN の価格は隣接する最大 2 個のトゥルーレンジを NaN にし、それらをウィンドウに含む出力だけが NaN になります。

無限大の価格によって未定義となる演算も NaN になります。

パラメータ:

  • high (Tensor) -- 高値を含む入力テンソル。

  • low (Tensor) -- 安値を含む入力テンソル。

  • close (Tensor) -- 終値を含む入力テンソル。

  • span (int, optional) -- トゥルーレンジの平均化に用いるウィンドウサイズ。デフォルトは 14 です。

  • use_sma (bool, optional) -- True の場合、ワイルダー平滑化の代わりに単純移動平均を使用します。デフォルトは False です。

  • dim (int, optional) -- ATR を計算する次元。デフォルトは -1（最後の次元）です。

戻り値:

ATR 値を含む、ブロードキャスト後の入力形状のテンソル（次元に沿った最初の span 個の要素は NaN です）。

戻り値の型:

Tensor

例外:

  • ValueError -- span が正でない場合。

  • TypeError -- span が整数でない場合（bool も拒否されます）。

  • TypeError -- high、low、close のいずれかが浮動小数点テンソルでない場合。

サンプル

>>> high = torch.tensor([10.0, 12.0, 11.0, 14.0])
>>> low = torch.tensor([9.0, 10.0, 9.0, 11.0])
>>> close = torch.tensor([9.5, 11.0, 10.0, 13.0])
>>> QF.atr(high, low, close, span=2)
tensor([   nan,    nan, 2.2500, 3.1250])

>>> QF.atr(high, low, close, span=2, use_sma=True)
tensor([   nan,    nan, 2.2500, 3.0000])

>>> # 一定の価格では、ウォームアップ後の ATR は 0 になります。
>>> c = torch.full((5,), 3.0)
>>> QF.atr(c, c, c, span=2)
tensor([nan, nan, 0., 0., 0.])

注釈

入力が OHLC の不変条件（high >= low や low <= close <= high など）を満たしているかどうかは検証されません。各出力は、与えられた入力に対して上記の式を単純に適用した結果になります。不変条件を満たす入力では、トゥルーレンジおよび ATR は常に非負となり、一定の価格では ATR は 0 になります。
