rand

rand(*size, dtype=None, device=None)[ソース]

区間 \([0, 1)\) 上の一様分布に従う乱数で埋められたテンソルを返します。

torch.rand() と異なり、qfeval_functions.random.seed() でシードを固定した場合、乱数はデバイスに依存しない乱数生成器によって生成されるため、結果はどのデバイスでも再現可能です。fast=True でシードを設定した場合、この関数は速度を優先して torch.rand() にフォールバックし、この再現性は保証されなくなります。

パラメータ:

  • *size (int) -- 出力テンソルの形状を定義する整数のシーケンス。

  • dtype (torch.dtype, optional) -- 返されるテンソルの望ましいデータ型。デフォルトは torch.float32 です。

  • device (torch.device, optional) -- 返されるテンソルの望ましいデバイス。デフォルトは現在のデバイスを使用します。

戻り値:

\([0, 1)\) の一様乱数で埋められた、指定された形状のテンソル。

戻り値の型:

Tensor

サンプル

>>> import qfeval_functions
>>> with qfeval_functions.random.seed(1):
...     x = QF.rand(2, 3)
>>> x
tensor([[0.2407, 0.7296, 0.5584],
        [0.5268, 0.1469, 0.9072]])

参考

  • rand_like(): 別のテンソルと同じ形状の一様乱数テンソル。

  • randn(): 標準正規分布に従う乱数。

  • randint(): 一様なランダム整数。

  • randperm(): 整数のランダムな順列。
