rms

rms(x, dim=(), keepdim=False)[ソース]

指定された次元 dim において、入力テンソルの各行の二乗平均平方根を返します。dim が次元のリストである場合、すべての次元にわたって集約します。

二乗平均平方根（RMS）は次のように定義されます:

\[\text{RMS}(x) = \sqrt{\frac{1}{n} \sum_{i=1}^{n} x_i^2}\]

これは符号によらず値の大きさを測るもので、シグナルやリターンの大きさを定量化するためによく用いられます。

パラメータ:

  • x (Tensor) -- 入力テンソル。

  • dim (int or tuple of ints, optional) -- 縮約する次元（複数可）。デフォルトは ()（すべての次元にわたって縮約）です。

  • keepdim (bool, optional) -- 出力テンソルが dim を保持するかどうか。デフォルトは False です。

戻り値:

指定された次元にわたる入力テンソルの二乗平均平方根。

戻り値の型:

Tensor

サンプル

>>> x = torch.tensor([1.0, -2.0, 3.0, -4.0])
>>> QF.rms(x)
tensor(2.7386)

>>> x = torch.tensor([[1.0, -2.0], [3.0, -4.0]])
>>> QF.rms(x, dim=1)
tensor([1.5811, 3.5355])
