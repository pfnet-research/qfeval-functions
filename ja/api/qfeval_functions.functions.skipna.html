skipna

skipna(f, *xs, dim=-1)[ソース]

NaN を取り除いた上で、与えられたデータを与えられた関数に適用します。

この関数は、NaN に対応していない関数を NaN を含むデータに適用できるようにします。指定された次元に沿って、まず NaN でない値を（順序を保ったまま）前方に詰め、その後ろに NaN 値を配置します。次に、詰められたテンソルに関数 f を適用し、最後に結果を NaN でない値の元の位置に戻します。いずれかの入力テンソルで NaN だった位置は、出力でも NaN になります。

注意: 与えられる関数 f は入力の形状を保持し、入力の \(i\) 番目の要素を出力の \(i\) 番目の要素に対応付けるものでなければなりません（例: 累積演算や要素ごとの演算）。

パラメータ:

  • f (Callable[..., Tensor]) -- 適用する関数。xs と同じ数のテンソルを受け取り、同じ形状のテンソルを返します。

  • *xs (Tensor) -- 入力テンソル。すべて同じ形状でなければなりません。複数のテンソルが与えられた場合、いずれかのテンソルで NaN である位置は、すべてのテンソルで欠損として扱われます。

  • dim (int, optional) -- NaN でない値を詰める次元。デフォルトは -1（最後の次元）です。

戻り値:

NaN でない値に f を適用した結果を含む、入力と同じ形状のテンソル。いずれかの入力テンソルが NaN である位置は NaN になります。

戻り値の型:

Tensor

サンプル

>>> # NaN をスキップした累積和。
>>> x = torch.tensor([1.0, nan, 2.0, nan, 3.0])
>>> QF.skipna(lambda a: a.cumsum(-1), x)
tensor([1., nan, 3., nan, 6.])

参考

  • apply_for_axis(): 2 次元入力を想定した関数を指定した次元に沿って適用します。

  • fillna(): NaN 値を除去する代わりに置き換えます。
