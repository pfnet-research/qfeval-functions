slope

slope(x, y, dim=None, keepdim=False)[ソース]

指定された次元 dim において、y を x に回帰させた単回帰の傾きを返します。

この関数は、回帰式 \(y = \alpha + \beta x\) の最小二乗法による傾き係数 \(\beta\) を計算します:

\[\beta = \frac{\sum_i (x_i - \bar{x})(y_i - \bar{y})} {\sum_i (x_i - \bar{x})^2}\]

クオンツファイナンスでは、例えば市場リターンに対する資産リターンのベータを推定するために用いられます。

注意：この計算は単純線形回帰の傾き β の計算に基づいています：https://en.wikipedia.org/wiki/Simple_linear_regression

パラメータ:

  • x (Tensor) -- 説明変数（独立変数）の値を含む入力テンソル。

  • y (Tensor) -- 目的変数（従属変数）の値を含む入力テンソル。その形状は x の形状にブロードキャスト可能でなければなりません。

  • dim (int or tuple of ints, optional) -- 縮約する次元（複数可）。デフォルトは ()（すべての次元にわたって縮約）です。

  • keepdim (bool, optional) -- 出力テンソルが dim を保持するかどうか。デフォルトは False です。

戻り値:

指定された次元にわたる線形回帰の傾き係数。

戻り値の型:

Tensor

サンプル

>>> x = torch.tensor([1.0, 2.0, 3.0, 4.0])
>>> y = torch.tensor([2.0, 4.0, 6.0, 8.0])
>>> QF.slope(x, y)
tensor(2.)

>>> y = torch.tensor([1.0, 3.0, 2.0, 5.0])
>>> QF.slope(x, y)
tensor(1.1000)

注釈

すべての x の値が同一（分散ゼロ）の場合、傾きは数学的に未定義であり、結果は NaN になります。
