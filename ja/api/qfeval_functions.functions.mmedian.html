mmedian

mmedian(x, span, dim=-1)[ソース]

テンソルの移動中央値（スライディングウィンドウ中央値）を計算します。

この関数は、指定された次元に沿ってサイズ span のスライディングウィンドウ内の要素の中央値を計算します。出力テンソルの形状は入力テンソルと同じです。スライディングウィンドウが先行する要素を完全にカバーできない場合（すなわち、指定された次元に沿って最初の span - 1 要素の場合）、結果は nan となります。

\(s_0 \le s_1 \le \dots \le s_{\text{span}-1}\) をウィンドウ内の値をソートしたものとすると、移動中央値は次のようになります:

\[\begin{split}\text{MMEDIAN}[i] = \begin{cases} s_{(\text{span}-1)/2} & \text{if } \text{span} \text{ is odd} \\ \left(s_{\text{span}/2-1} + s_{\text{span}/2}\right) / 2 & \text{if } \text{span} \text{ is even} \end{cases}\end{split}\]

これは QF.mquantile(x, span, 0.5, dim) と等価であり、pandas.DataFrame.rolling(span).median() と互換性があります。ウィンドウサイズが偶数の場合、中央の 2 つの値が平均されます（線形補間）。

パラメータ:

  • x (Tensor) -- 値を含む入力テンソル。浮動小数点テンソルである必要があります。

  • span (int) -- スライディングウィンドウのサイズ。正の値である必要があります。

  • dim (int, optional) -- 移動中央値を計算する次元。デフォルトは -1（最後の次元）です。

戻り値:

入力と同じ形状のテンソルで、移動中央値の値を含みます。指定された次元に沿った最初の span - 1 要素は nan になります。

戻り値の型:

Tensor

例外:

  • TypeError -- span が整数でない場合（bool も拒否されます）。

  • ValueError -- span が正でない場合。

  • TypeError -- x が浮動小数点テンソルでない場合。

サンプル

>>> # 奇数のウィンドウサイズでの移動中央値
>>> x = torch.tensor([1.0, 3.0, 2.0, 5.0, 4.0])
>>> QF.mmedian(x, span=3)
tensor([nan, nan, 2., 3., 4.])

>>> # 偶数のウィンドウサイズでは中央の 2 つの値が平均されます
>>> QF.mmedian(x, span=2)
tensor([   nan, 2.0000, 2.5000, 3.5000, 4.5000])

>>> # 最初の次元に沿った移動中央値
>>> x = torch.tensor([[1.0, 2.0],
...                   [5.0, 3.0],
...                   [3.0, 7.0]])
>>> QF.mmedian(x, span=3, dim=0)
tensor([[nan, nan],
        [nan, nan],
        [3., 3.]])

>>> # NaN を含むウィンドウは NaN になります
>>> QF.mmedian(torch.tensor([1.0, nan, 3.0, 4.0, 5.0]), span=2)
tensor([   nan,    nan,    nan, 3.5000, 4.5000])

注釈

ウィンドウ内に NaN 値が 1 つでも含まれる場合、そのウィンドウの移動中央値は NaN になります。pandas.DataFrame.rolling とは異なり、NaN 値をスキップする min_periods のようなオプションはありません。

注釈

この関数は mquantile() の自動アルゴリズム選択に処理を委譲します。狭いウィンドウではベクトル化されたウィンドウ演算を、より大きなウィンドウのワークロードでは Wavelet Matrix による範囲選択を使用します。
