eigh

eigh(tensor, uplo='L')[ソース]

対称行列（エルミート行列）の固有値と固有ベクトルを計算します。

この関数は、実対称行列または複素エルミート行列の固有値と固有ベクトルを計算します。固有値は昇順に返され、対応する固有ベクトルは正規化されます。この実装では、CPU テンソルには NumPy を、CUDA テンソルには CuPy を使用しています。

注釈

この関数は自動微分（autograd）をサポートしていません。

注釈

入力の対称性は検証されません。uplo で選択された三角部分のみが使用され、もう一方の部分は無視されるため、非対称な入力を与えると、（対称化された）別の行列に対する結果が警告なく返されます。

パラメータ:

  • tensor (Tensor) -- 形状が (..., N, N) の対称行列（実数の場合）またはエルミート行列（複素数の場合）。uplo パラメータに応じて、上三角部分または下三角部分が使用されます。

  • uplo (str, optional) --

    使用する行列の三角部分を示します：

    • 'L' または 'l': 下三角部分を使用する（デフォルト）

    • 'U' または 'u': 上三角部分を使用する

戻り値:

以下の要素を含むタプル:

  • 固有値: 昇順に並んだ固有値を含む形状 (..., N) のテンソル

  • 固有ベクトル: 形状が (..., N, N) のテンソルで、列は対応する固有値の正規化固有ベクトルです

戻り値の型:

Tuple[Tensor, Tensor]

サンプル

>>> # 対称行列を作成
>>> A = torch.tensor([[4.0, -2.0],
...                   [-2.0, 3.0]])
>>> eigenvalues, eigenvectors = QF.eigh(A)
>>> eigenvalues
tensor([1.4384, 5.5616])

>>> # 検証: A @ v = λ @ v
>>> torch.allclose(A @ eigenvectors, eigenvectors @ torch.diag(eigenvalues))
True

>>> # 上三角部分を使用
>>> B = torch.tensor([[1.0, 2.0, 3.0],
...                   [0.0, 4.0, 5.0],
...                   [0.0, 0.0, 6.0]])
>>> eigenvalues, eigenvectors = QF.eigh(B, uplo='U')
