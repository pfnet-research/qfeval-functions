nanmin

nanmin(x, dim, keepdim=False)[ソース]

NaN 値を無視して、指定された次元に沿って最小値とそのインデックスを返します。

この関数は、指定された次元に沿って最小値を計算し、NaN 値を計算対象から除外します。元のテンソルにおける最小値とその対応するインデックスの両方を返します。これは torch.min と似ていますが、NaN 値を考慮した動作をします。

この関数は以下のエッジケースを適切に処理します：

  • 純粋な NaN スライス（値は NaN として返されます）

  • NaN 値と正の無限大値が混在している場合

  • すべての正の無限大値（正の無限大を返す）

パラメータ:

  • x (Tensor) -- 値を含む入力テンソル。

  • dim (int) -- 最小値を求める次元を指定します。

  • keepdim (bool, optional) -- 出力テンソルが dim を保持するかどうか。デフォルトは False。

戻り値:

以下の要素を含む名前付きタプル:

  • values (Tensor): 指定された次元に沿って計算された最小値。NaN 値は無視されます。スライスが NaN 値のみで構成されている場合、結果は NaN となります。

  • indices (Tensor): 元のテンソルにおける最小値のインデックス。

戻り値の型:

NanminResult

サンプル

>>> # NaN 値を含む単純な最小値
>>> x = torch.tensor([[1.0, nan, 3.0],
...                   [4.0, 5.0, nan]])
>>> result = QF.nanmin(x, dim=1)
>>> result.values
tensor([1., 4.])
>>> result.indices
tensor([0, 0])

>>> # すべて NaN のスライス
>>> x = torch.tensor([[1.0, 2.0],
...                   [nan, nan]])
>>> result = QF.nanmin(x, dim=1)
>>> result.values
tensor([1., nan])
>>> result.indices
tensor([0, 0])

>>> # 正の無限大を含む
>>> x = torch.tensor([[1.0, inf, 3.0],
...                   [nan, 2.0, inf]])
>>> result = QF.nanmin(x, dim=1)
>>> result.values
tensor([1., 2.])
>>> result.indices
tensor([0, 1])

>>> # keepdim を使用
>>> x = torch.tensor([[nan, 2.0, 1.0],
...                   [3.0, nan, 4.0]])
>>> result = QF.nanmin(x, dim=1, keepdim=True)
>>> result.values
tensor([[1.],
        [3.]])
>>> result.indices
tensor([[2],
        [0]])

注釈

次元に沿ったすべての値が NaN の場合、返される値は NaN となり、対応するインデックスは 0 になります。このインデックスは有効な要素を指しません。

参考

  • nanmax(): NaN を考慮した最大値関数。

  • nanamin(): 複数次元に対応した NaN 対応の最小値。

  • torch.min(): 標準の最小値関数（NaN は伝播します）。
