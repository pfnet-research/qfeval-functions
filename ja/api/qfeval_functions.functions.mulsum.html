mulsum

mulsum(x, y, dim=None, keepdim=False, mean=False, *, _ddof=0)[ソース]

メモリ効率に優れた方法で、要素ごとの積の和または平均を計算します。

この関数は、中間的な積テンソルをメモリ上に作成することなく、2 つのテンソルの要素ごとの積の和（または平均）(x * y).sum(dim) または (x * y).mean(dim) を計算します。これは、特に大規模なテンソルを扱う場合や、ブロードキャスト操作によって中間テンソルが非常に大きくなり、利用可能なメモリを超える可能性がある場合に特に重要です。

パラメータ:

  • x (Tensor) -- 最初の入力テンソル。

  • y (Tensor) -- 第 2 の入力テンソル。x とブロードキャスト可能である必要があります。

  • dim (None, int, or tuple of ints, optional) -- 和または平均を計算する次元を指定します。None（デフォルト）の場合、全ての次元にわたって計算が行われます。

  • keepdim (bool, optional) -- 出力テンソルが dim を保持するかどうか。デフォルトは False。

  • mean (bool, optional) -- True の場合、和ではなく平均を計算します。デフォルトは False（和を計算）です。

  • _ddof (int, optional) -- 平均計算における自由度の増分。使用する除数は N - _ddof で、ここで N は要素数を表します。デフォルト値は 0 です。これは内部パラメータです。

戻り値:

要素ごとの積の和または平均。形状は入力次元、dim、および keepdim パラメータに依存します。

戻り値の型:

Tensor

サンプル

>>> # 単純な要素ごとの積の合計
>>> x = torch.tensor([1.0, 2.0, 3.0])
>>> y = torch.tensor([2.0, 3.0, 4.0])
>>> QF.mulsum(x, y)
tensor(20.)

>>> # (x * y).sum() と等価
>>> torch.allclose(QF.mulsum(x, y), (x * y).sum())
True

>>> # 合計の代わりに平均
>>> QF.mulsum(x, y, mean=True)
tensor(6.6667)

>>> # 次元を指定した 2 次元テンソル
>>> x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
>>> y = torch.tensor([[2.0, 1.0], [1.0, 2.0]])
>>> QF.mulsum(x, y, dim=1)
tensor([ 4., 11.])

>>> # メモリ効率の良いブロードキャスト
>>> x = torch.randn(1000, 1)
>>> y = torch.randn(1, 1000)
>>> # 1000x1000 の中間テンソルを作らずに効率的に計算
>>> result = QF.mulsum(x, y)

>>> # keepdim を使用
>>> x = torch.tensor([[[1.0, 2.0]], [[3.0, 4.0]]])
>>> y = torch.tensor([[[2.0, 1.0]], [[1.0, 2.0]]])
>>> QF.mulsum(x, y, dim=(1, 2), keepdim=True)
tensor([[[ 4.]],

        [[11.]]])

注釈

x と y は同じ dtype でなければなりません。異なる dtype（例: 整数テンソルと浮動小数点テンソル）を混在させると、暗黙的にキャストされる代わりに RuntimeError が送出されます。
