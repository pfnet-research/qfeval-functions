orthogonalize

orthogonalize(x, y, dim=-1)[ソース]

指定された次元に沿って、x を y に対して直交化します。

この関数は x から y への正射影を差し引くことで、結果が dim に沿って y と直交する（すなわち dim に沿った内積が 0 になる）ようにします:

\[x - \frac{\langle x, y \rangle}{\langle y, y \rangle} y\]

これはグラム・シュミット過程の基本ステップです。クオンツファイナンスでは、あるシグナルを別のファクターに対して中立化する（例: アルファシグナルから市場エクスポージャーを除去する）のに有用です。

パラメータ:

  • x (Tensor) -- 直交化するテンソル。

  • y (Tensor) -- x を直交化する際の基準となるテンソル。その形状は x の形状にブロードキャスト可能でなければなりません。

  • dim (int, optional) -- 直交化を行う次元。デフォルトは -1（最後の次元）です。

戻り値:

指定された次元に沿って y と直交する、x と同じ形状のテンソル。

戻り値の型:

Tensor

サンプル

>>> x = torch.tensor([1.0, 2.0, 3.0])
>>> y = torch.tensor([1.0, 1.0, 1.0])
>>> QF.orthogonalize(x, y)
tensor([-1.,  0.,  1.])

>>> # 各行は dim=1 に沿って独立に直交化されます。
>>> x = torch.tensor([[1.0, 2.0], [3.0, 4.0]])
>>> y = torch.tensor([[1.0, 0.0], [0.0, 1.0]])
>>> QF.orthogonalize(x, y, dim=1)
tensor([[0., 2.],
        [3., 0.]])

注釈

y が次元に沿ってゼロベクトルの場合、射影の計算でゼロ除算が発生し、結果は NaN になります。

  • project(): 射影行列を用いてテンソルを射影する関数。
